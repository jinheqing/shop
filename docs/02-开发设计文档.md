# 英国高端定制普洱茶系统｜开发设计文档（可直接编码版）

> **文档目标**：开发团队按此文档可直接编码。所有数据库字段、API endpoint、JSON schema、前端表单控件、管理后台配置项均已明确。
> **前后端字段对齐**：数据库字段 = Go struct 字段 = API JSON 字段 = 前端表单字段，无漂移。
> **项目定位**：顾问式私域定制普洱茶跨境系统，国内茶商自有茶山+工厂，面向英国高端客户。

---

## 技术栈确认

| 维度 | 选型 |
|------|------|
| 后端 | Go 1.22+ + Gin + GORM 1.30+ |
| 数据库 | PostgreSQL 16 + Redis 7 |
| 消息队列 | RabbitMQ |
| 翻译引擎 | NLLB-200 1.3B + Whisper base + CTranslate2 + FastAPI（本地 CPU） |
| 公开网站 | Vite 5 + Vue 3 + TS + Tailwind CSS + shadcn-vue |
| 顾问后台 | Vite 5 + Vue 3 + TS + Element Plus + ECharts（pnpm monorepo 同仓库） |
| 移动端 | Flutter 3.38+ + livekit_client: ^2.12.0 + Dio + Riverpod |
| 直播 | Livekit 自部署 + MediaMTX（WireGuard 内网 10.10.0.0/24） |
| 部署 | 宝塔面板 + Nginx + Docker Compose |
| PDF | unipdf/unipdf（纯 Go） |
| 支付 | 2Checkout + PayPal |
| 邮件 | Mailgun（EU 节点） |

## 第二部分：后端 API 完整规范

> Base URL: `https://api.ourdomain.com/api/v1`
> 认证：`Authorization: Bearer {jwt}`
> 响应格式：`{"code": 0, "message": "ok", "data": {...}, "request_id": "uuid"}`
> 分页：`GET ?page=1&size=20` → `{"list": [...], "total": 100, "page": 1, "size": 20}`

### Flutter 直播推流核心代码

```dart
// services/livekit_service.dart
import 'package:livekit_client/livekit_client.dart';

class LiveService {
  final Room room = Room();

  Future<void> startLive({
    required String livekitUrl,
    required String token,
  }) async {
    await room.connect(livekitUrl, token);
    await room.localParticipant.setCameraEnabled(true);
    await room.localParticipant.setMicrophoneEnabled(true);
  }

  Future<void> stopLive() async => await room.disconnect();
}
```
