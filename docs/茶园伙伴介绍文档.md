## 一、我们是谁

我们是一个**项目共同体**——不是你卖茶、我卖货的买卖关系，而是从云南茶山到伦敦客户杯中，一条完整的品牌价值链。

你守着茶山，管着采摘、晒青、揉捻、发酵；我们守着平台，管着拍视频、引流量、做顾问、管会员、发物流。你的茶到了英国客户手里，客户知道这茶来自哪座山、哪天采的、谁做的——这就是我们的共同体。

**你负责：** 好茶、好故事、好工艺
**我们负责：** 拍纪录片、引流量、做品牌、管客户、发物流、收付款
**共同目标：** 让英国高端消费者认识你的茶山，愿意为你的茶付高端的价格

## 二、为什么从 YouTube 引流

### 英国高端消费者把 YouTube 当"第二客厅"

这不是我们拍脑袋想出来的。以下是英国官方和权威机构的数据：

**1. YouTube 已经和 BBC 并列英国第一视频平台**

根据英国文化、媒体和体育部（DCMS）2026年6月发布的《媒体绿皮书》，引用英国收视率调查机构 BARB 的数据：

> 2025年第三季度，YouTube 和 BBC 各占英国全部视频观看时长的 **19%**，并列全英第一。排名第三的 ITV 仅占 11.7%，Netflix 仅占 10.4%。

**2. 英国 YouTube 用户 5550 万**

根据 Search Engine Land 2026年9月数据，英国 YouTube 月活跃用户达 **5550万**，占英国总人口（约6800万）的 **81.6%**。

**3. 英国人每天在 YouTube 上看 41 分钟**

根据英国通信管理局 Ofcom《2026年媒体国家报告》（2026年7月发布）：

> 2025年英国人在视频分享平台上平均每天观看 **51分钟**，其中 YouTube 占 **41分钟**，比2024年增长 18%。YouTube 在电视大屏上的观看时长从2022年的9分钟增长到2025年的19分钟，三年翻了 **111%**。

**4. 16-24岁人群：74%的视频时间在流媒体和视频平台上**

同一份 Ofcom 报告指出，16-24岁英国人的视频观看时间中，**74%** 花在流媒体和视频分享平台上，只有 9% 看传统电视。25-34岁人群这个比例是 **69%**。

**5. YouTube 广告直接影响了 63% 观众的购买决策**

根据 Silverpush《2025年YouTube零售报告》：

> **63%** 的观众表示 YouTube 广告直接影响了他们的购买决策。YouTube 对品牌官网直销的增量提升是通常报告数据的 **3.4倍**（Haus Research）。

**6. 英国 YouTube 广告投入 24 亿英镑**

根据 eMarketer UK，2025年英国 YouTube 广告支出达 **24亿英镑**，其中创作者驱动的广告投放同比增长 **18%**。

**7. 英国创作者经济 17 亿英镑，2026年预计超 84 亿**

根据 Ofcom《2026年在线国家报告》，英国创作者经济规模已达 **17亿英镑**。eMarketer UK 预测2026年将超过 **84亿英镑**。

### 为什么我们选择 YouTube 而不是其他平台

| 对比项 | YouTube | TikTok | Instagram |
|--------|---------|--------|-----------|
| 内容深度 | 长视频，能讲完整故事（15-40分钟纪录片） | 15-60秒短视频，只能做碎片 | 图片+短视频，不适合深度叙事 |
| 用户心态 | "第二客厅"，坐下来认真看 | 刷完就走，注意力极短 | 滑过去，视觉刺激为主 |
| 信任建立 | 纪录片式叙事建立深度信任 | 娱乐为主，信任难沉淀 | 颜值驱动，与产品品质无关 |
| 英国覆盖率 | 5550万用户，全英 81.6% | 4.4%视频份额 | 穿插广告效果有限 |
| 高端客户匹配 | 高收入人群停留时间长 | 年轻化、低客单价 | 品牌展示可以，深度转化弱 |
| 算法推荐 | 基于兴趣长期推荐，纪录片长尾效应强 | 爆款逻辑，过两天就没了 | Feed流很快被淹没 |

**结论：** YouTube 是唯一能让我们用15-40分钟纪录片讲完一个茶山故事、并且让英国高端客户坐下来认真看的平台。

## 三、用户完整旅程

### 客户侧：从第一次看到到收到茶

```
第1步 · 了解
  英国客户在 YouTube 上看到我们的纪录片
  → 被茶山风景、匠人故事吸引
  → 点击视频简介里的链接，来到我们的网站

第2步 · 深入了解
  到了网站首页，看到：
  → 茶园故事页：每座茶山的详细介绍（位置、海拔、树龄、采茶人）
  → 茶山慢直播页：24小时实时看茶山
  → SGS品质页：每批茶的农残、重金属、微生物检测报告
  → 关于我们页：品牌故事、团队介绍

第3步 · 看产品
  浏览定制拼配页（Bespoke）
  → 看到各种茶的类型：普洱生饼/熟饼、滇红、白茶、古树散茶
  → 看到可选的茶园、年份、工艺
  → 看到包装选项（礼盒、散装、定制刻字）
  → 看到价格范围和预计交付时间

第4步 · 咨询顾问
  点击页面右下角的小铃铛或"Speak with an Advisor"
  → 进入聊天页面
  → 和专属茶顾问一对一沟通
  → 顾问了解客户口味偏好、预算、用途（自饮/送礼/收藏）
  → 顾问推荐适合的茶品和拼配方案

第5步 · 定制
  顾问帮客户提交定制需求表
  → 选茶类型、茶园、工艺、重量、数量、包装
  → 填写特殊要求（如刻字、手写卡片、特定日期送达）
  → 系统生成报价单，客户确认

第6步 · 看到质量保证
  客户在确认订单前，可以看到：
  → SGS 检测报告（每批茶都有独立检测）
  → 溯源信息（扫码可知：哪座山、哪天采、谁做的、检测编号）
  → 14天无理由退换承诺
  → 全程物流追踪

第7步 · 下单成交
  客户确认报价 → 系统生成订单 → 支付
  → 个人客户：信用卡/借记卡支付（2Checkout）
  → 企业客户：申请发票，填写公司名和VAT号，走对公转账
  → 支付成功 → 顾问收到通知 → 开始安排生产

第8步 · 全程追踪
  客户在个人账户页可以看到订单的完整旅程：
  → 已下单 → 已付款 → 制作中 → 出关中 → 已发货 → 已签收
  → 每一步都有时间戳和顾问备注
  → 物流信息实时显示：快递公司、运单号、预计到达时间
  → 客户随时可以点"View Journey"展开完整轨迹
```

  → 提醒支付方式
  → 告知预计交付时间

  → 客户确认后重新生成订单

  → 订单进入制作流程
  → 顾问更新物流信息（快递公司、运单号、预计到达时间）
  → 客户在个人账户实时看到每一步
  → 客户收到茶 → 订单完成 → 顾问跟进品饮反馈

## 四、网站设计理念

### 对标欧洲奢侈品营销模式

我们的网站不是"超市货架"，而是"私人会客厅"。这是对标欧洲主流高端商品销售平台（如 Net-a-Porter、Mr Porter、Selfridges 线上旗舰店）的设计逻辑：

| 设计要素 | 普通电商做法 | 我们的做法（奢侈品逻辑） |
|----------|-------------|------------------------|
| **首页** | 商品罗列、打折促销 | 品牌叙事、茶园大片、溯源承诺，先建立信任再展示产品 |
| **产品页** | 价格+参数+购物车 | 定制入口：先了解你的需求，再为你拼配专属茶品 |
| **购物流程** | 自助选品→加购物车→结账 | 先和顾问沟通→顾问帮你定制→生成专属报价→再下单 |
| **客服** | 在线客服机器人/工单 | 专属茶顾问一对一，像私人购物顾问一样服务 |
| **质量保证** | 写一句"品质保证" | 每批茶都有 SGS 检测报告，扫码可查从茶山到茶杯的全流程 |
| **售后** | 7天无理由 | 14天无理由退换 + 顾问跟进品饮反馈 |
| **会员** | 积分兑换优惠券 | 会员分组制：不同等级享受不同权益（线下茶会、私人定制、茶园访问权） |

### 会员组设计

这是我们的核心差异化设计之一。不是传统的"积分制"，而是对标英国私人俱乐部（如 Soho House、5 Hertford Street）的**分组制**：

| 会员组 | 门槛 | 享受权益 |
|--------|------|----------|
| **新茶友** | 注册即加入 | 可浏览所有公开内容、可咨询顾问、可下单 |
| **品鉴会员** | 累计消费达设定金额 | 优先客服、新品试饮优先权、专属品鉴会邀请 |
| **KOL 伙伴** | 推荐人累计有效推荐达标后自动加入 | 专属折扣、私人定制服务、受邀参加茶山实地考察 |
| **企业客户** | 提供公司信息和VAT号 | 批量采购价、企业发票、专属客户经理、定制礼盒 |
| **茶园伙伴** | 茶园方 | 茶山慢直播接入权、产量管理、订单追踪、收益结算 |

**为什么这样设计：** 英国高端消费者习惯"被识别身份"——他们不在乎打折多少，在乎"我是谁、我有什么特权"。Soho House 不是靠便宜吸引会员，而是靠"你能进来证明你是什么人"。我们的会员组同理。

### 推荐人设计

推荐不是"发优惠券让朋友省钱"，而是**名字推荐制**——对标英国上流社会的"私人引荐"文化：

**三个入口：**

| 入口 | 场景 | 怎么操作 |
|------|------|----------|
| **注册时填名字** | 新客户在注册页选择"朋友推荐" → 输入朋友名字 → 系统自动匹配 | 如果朋友已注册，自动建立推荐关系 |
| **短链私发** | 老客户在个人账户点"Copy Link" → 复制一条私人短链 → WhatsApp 发给朋友 | 朋友点开短链 → 直接跳到注册页 → 系统自动识别推荐人 |
| **顾问手动补建** | 顾问在后台 → 推荐人管理 → 手动关联两个人 | 兜底场景：客户说是朋友推荐但当时没填，顾问手动补上 |

**推荐奖励逻辑：**
- 朋友下单且金额达到后台设定的门槛 → 推荐人获得奖励（礼物/优先权）
- 推荐人累计有效推荐数达标 → 系统自动拉进 KOL 伙伴组
- 门槛可在后台随时调整，不需要重新上线

**为什么这样设计：** 英国高端人群不接受"到处发优惠券"的推销方式。名字推荐保持了私密性和体面——"我介绍你认识一个好朋友"，而不是"帮我砍一刀"。

## 五、为什么不做亚马逊、速卖通、TikTok Shop

| 对比项 | 亚马逊 / 速卖通 / TikTok Shop | 我们的独立平台 |
|--------|-------------------------------|---------------|
| **品牌定位** | 大卖场，价格驱动 | 私人会客厅，价值驱动 |
| **客户质量** | 比价用户，忠诚度为零 | 顾问服务的客户，复购率高 |
| **定价权** | 平台压价，你跟别人的茶比价格 | 你自己定价，客户为故事和品质买单 |
| **数据归属** | 平台拥有客户数据，你看不到 | 客户数据、购买记录、沟通历史全在你手里 |
| **品牌叙事** | 不可能。商品页就是一张参数表 | 15-40分钟纪录片 + 茶园故事页 + 慢直播 + 溯源 |
| **顾问服务** | 不可能。客户自己选自己买 | 一对一茶顾问，帮客户定制拼配 |
| **会员体系** | 没有。客户就是来买一次 | 分组制会员，不同等级不同权益 |
| **推荐系统** | 没有。客户买完就走 | 名字推荐制，老客户带新客户，自动进组 |
| **品质背书** | 不可能展示。最多写一句"品质保证" | 每批茶都有 SGS 检测报告，扫码可查全流程 |
| **平台抽成** | 亚马逊 8-15% + 月费 + 广告费 | 零抽成（只有支付通道费约 2.9%） |
| **你的茶卖多少钱** | 被平台比价压到最低 | 你说了算 |
| **客户会不会回来找你** | 不会。下次搜出来的可能是别人的茶 | 会。客户登录自己的账号，看到自己的订单和顾问 |

**一句话：** 把云南古树普洱放在亚马逊上和越南茶包比价格，就像把爱马仕放在菜市场卖——不是茶不好，是放错了地方。

## 六、对标 JING Tea

JING Tea 是2004年在英国创立的高端茶品牌，在全球高端酒店（如四季酒店、丽思卡尔顿）的客房和下午茶中使用。他们做得很成功，是我们学习的对象。但我们的模式有本质不同：

### JING Tea 的模式

- **产品线：** 红茶、绿茶、白茶、乌龙茶、花茶，品类全但偏"大众高端"
- **采购模式：** 直接去各地茶园采购，但茶园是他们供应商，不是合伙人
- **销售模式：** 标准电商——浏览商品→加购物车→结账，和买书一样
- **品牌叙事：** 网站有茶园故事，但没有纪录片、没有直播、没有溯源
- **顾问服务：** 没有。客户自己选自己买
- **会员体系：** 没有。买完就是买完
- **推荐系统：** 没有
- **定制服务：** 没有。卖什么你买什么
- **品质背书：** 没有 SGS 检测报告公开展示
- **B2B：** 有批量采购入口，但没有企业发票/增值税管理
- **直播：** 没有
- **价格区间：** 礼盒约 £40-80，属于"买得起的高端"

### 我们的优势

| 优势 | 说明 |
|------|------|
| **纪录片引流** | YouTube 三部曲纪录片，15-40分钟讲完一个茶山故事，长尾效应持续引流。JING 没有这个 |
| **茶山慢直播** | 24小时实时看茶山，客户可以亲眼看到你的茶园。JING 没有这个 |
| **专属顾问制** | 一对一茶顾问帮客户定制，像私人购物顾问。JING 是自助式购物 |
| **定制拼配** | 客户可以指定茶园、工艺、包装，甚至刻字。JING 只能买现成的 |
| **SGS 检测报告** | 每批茶都有独立检测报告，公开可查。JING 没有公开展示 |
| **全程溯源** | 扫码可知：哪座山、哪天采、谁做的、检测编号、物流全程。JING 只有产地标注 |
| **会员分组制** | 不同等级不同权益，对标英国私人俱乐部。JING 没有会员体系 |
| **名字推荐制** | 老客户带新客户，自动进组。JING 没有推荐系统 |
| **企业客户** | VAT号管理、企业发票、专属客户经理。JING 有批发但没有完整的 B2B |
| **茶园合伙人** | 你不是供应商，你是合伙人——你的茶山、你的故事、你的品牌 |
| **价格定位更高** | 古树单株普洱饼 £100-500+，远超 JING 的 £40-80 区间，瞄准真正的高端市场 |
| **订单全程透明** | 客户在账户页看到订单每一步（下单→付款→制作→出关→发货→签收），每步带顾问备注和物流信息。JING 只有发货通知 |

### 我们的劣势（坦诚说）

| 劣势 | 说明 | 我们的应对 |
|------|------|-----------|
| **品牌知名度** | JING 做了20年，品牌已成熟。我们刚起步 | 纪录片持续输出 + 顾问服务口碑 + 老客户推荐裂变 |
